# Lumen v1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build Lumen v1, a native macOS menu bar app that connects/disconnects displays,
controls brightness (built-in + DDC), switches resolution/refresh/HiDPI, and applies named
presets from the menu or a global hotkey.

**Architecture:** A SwiftPM package `LumenCore` holds all logic. Pure pieces (DDC wire
format, AV-service matching, mode catalogue, preset planning, safety rules, persistence) are
test-driven with Swift Testing. One backend file set calls the private display APIs through
`dlsym` + `@convention(c)`. A thin SwiftUI app target (XcodeGen) owns an `@Observable`
controller, a `MenuBarExtra` popover and a Settings window.

**Tech Stack:** Swift 6.2 (language mode 6, complete concurrency checking), SwiftUI on
macOS 26, CoreGraphics + ColorSync + IOKit, private SkyLight/DisplayServices/IOAVService
symbols, Carbon hotkeys, ServiceManagement, XcodeGen 2.46, Swift Testing. No third-party
dependencies.

Design: `docs/plans/2026-09-14-lumen-design.md`.

---

## Conventions

- Run core tests: `cd Packages/LumenCore && swift test` (expected: all pass, 0 warnings about
  concurrency).
- Build the app: `xcodegen generate && xcodebuild -project Lumen.xcodeproj -scheme Lumen -configuration Debug -derivedDataPath build build`
- The generated `Lumen.xcodeproj` and `build/` are git-ignored.
- Commits: Conventional Commits, scope `core` or `app`.
- Persisted state: `~/Library/Application Support/Lumen/state.json` (one file: `schemaVersion`,
  `displays`, `presets`). This merges the design's "known-displays.json" and presets into
  one file.

**Step 3: Implement**

```swift
public enum DDCError: Error, Equatable, Sendable { case tooShort, badChecksum, wrongOpcode, unsupported, vcpMismatch }

public struct VCPValue: Equatable, Sendable {
    public let current: UInt16
    public let maximum: UInt16
    public var normalised: Double { maximum == 0 ? 0 : min(1, Double(current) / Double(maximum)) }
    public static func raw(forNormalised value: Double, maximum: UInt16) -> UInt16 {
        UInt16((min(1, max(0, value)) * Double(maximum)).rounded())
    }
}

public enum DDCPacket {
    public static let chipAddress: UInt32 = 0x37
    public static let dataAddress: UInt32 = 0x51
    public static let brightness: UInt8 = 0x10
    static let hostAddress: UInt8 = 0x6E

    public static func getVCPRequest(_ vcp: UInt8) -> [UInt8] {
        var bytes: [UInt8] = [0x82, 0x01, vcp]
        bytes.append(bytes.reduce(hostAddress ^ UInt8(dataAddress), ^))
        return bytes
    }

    public static func setVCPRequest(_ vcp: UInt8, value: UInt16) -> [UInt8] {
        var bytes: [UInt8] = [0x84, 0x03, vcp, UInt8(value >> 8), UInt8(value & 0xFF)]
        bytes.append(bytes.reduce(hostAddress ^ UInt8(dataAddress), ^))
        return bytes
    }

    static func replyChecksum(_ bytes: ArraySlice<UInt8>) -> UInt8 { bytes.reduce(0x50, ^) }

    public static func parseGetVCPReply(_ reply: [UInt8], vcp: UInt8) throws(DDCError) -> VCPValue {
        guard reply.count >= 11 else { throw .tooShort }
        guard replyChecksum(reply[0..<10]) == reply[10] else { throw .badChecksum }
        guard reply[2] == 0x02 else { throw .wrongOpcode }
        guard reply[3] == 0x00 else { throw .unsupported }
        guard reply[4] == vcp else { throw .vcpMismatch }
        return VCPValue(current: UInt16(reply[8]) << 8 | UInt16(reply[9]),
                        maximum: UInt16(reply[6]) << 8 | UInt16(reply[7]))
    }
}
```

### Task 3: Display model + AV-service matching (pure)

**Tests (write first):**
- `port(fromServicePath:)` extracts `dispext0` from
  `IOService:/…/dispext0:dcpav-service-epic:0/DCPAVServiceProxy`, `disp0` from the built-in
  path, `nil` from an unrelated path.
- `port(fromDeviceName:)` turns `dispext1@C4000000` into `dispext1`.
- Matches LS32D70xE (19501/30291/809582919) to `dispext0` and G81SF (19501/30540/811091798)
  to `dispext1` using the real attributes.
- Twin monitors (same vendor + model, different serials) match by serial.
- Serial 0 on the display falls back to vendor + model when exactly one candidate has them.
- Twin monitors that both report serial 0 return `nil` (ambiguous, DDC disabled).
- Built-in display returns `nil`.

**Implementation:** `FramebufferAttributes { port, vendor, model, serial, productName }`;
`AVServiceMatcher.port(for:among:)` filters exact vendor+model+serial (serial non-zero); if
exactly one → port; else candidates with vendor+model; exactly one → port; else nil. Port
parsing with a `/(disp(?:ext)?\d+):dcpav-service/` Regex literal.

**Commit:** `feat(core): match DDC channels to displays by product attributes`.

- Tests: `PresetPlannerTests.swift`, `SafetyRulesTests.swift`, `DisplayStatusTests.swift`,

**Status rules (tests first):**
- Online and active → `.online`.
- In the online list but inactive → `.disconnected`.
- Not online and `disconnectedByLumen` → `.disconnected`.
- Not online and not Lumen-disconnected → `.unavailable`.

**Planner tests:**
- Night (both externals off, built-in on at 0.10) from all-online → steps
  `[setBrightness(builtin, 0.10), disconnect(G81SF), disconnect(LS32)]`.
- Day (all on, built-in 0.6, G81SF mode) from Night state → `[connect(G81SF), connect(LS32),
  waitForOnline([G81SF, LS32]), setMode(G81SF, …), setBrightness(builtin, 0.6)]`.
- Target for an unknown or `.unavailable` display → no steps, `skipped: [.notAttached(name)]`.
- Target disconnecting the built-in → `skipped: [.builtinStaysOn(name)]`.
- Clamshell (built-in unavailable) applying Night → keeps one external, skip
  `.wouldLeaveNoDisplay(name)` for the last one.
- Brightness is clamped to 0…1; brightness/mode on a target that is `connected: false` are
  ignored.
- Displays not named in the preset are untouched and count as active.

**Safety tests:** `SafetyRules.canDisconnect(uuid, in:)` is false for the only online display
and true otherwise; `false` for an unknown uuid.

**Factory tests:** `seedPresets(from:brightness:)` gives Night (externals off, built-in 0.10,
⌃⌥⌘N, symbol `moon.stars`) and Day (externals on, built-in at captured brightness, ⌃⌥⌘D,
symbol `sun.max`); `capture(name:displays:)` records connection, brightness and mode for
online displays and `connected: false` for disconnected ones, and skips unavailable ones.

**Backend rules:**

  `CGCompleteDisplayConfiguration(.forSession)`; cancel the config on any failure.

- DDC write: up to 3 attempts on a non-zero `IOReturn`.
- Brightness routes to DisplayServices when `DisplayServicesCanChangeBrightness(id)`,
  otherwise DDC via the matched AV service; no match → `DisplayError.brightnessUnsupported`.
